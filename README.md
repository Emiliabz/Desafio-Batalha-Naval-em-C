# ⚓ Desafio: Batalha Naval em C

Repositório dedicado ao desenvolvimento de um simulador do clássico jogo Batalha Naval utilizando a Linguagem C. O foco principal deste projeto é a construção, manipulação e exibição de matrizes na memória para o posicionamento estratégico de navios em um tabuleiro digital.

---

## 🚀 Tecnologias e Ferramentas

* **Linguagem C** (Lógica estruturada e manipulação de arrays multidimensionais)
* **GCC / MinGW** (Compilador)
* **Visual Studio Code** ou IDE equivalente

---

## 📂 Estrutura do Repositório

O projeto é composto pelos seguintes arquivos:

* **`batalhanaval.c`**: Código-fonte principal onde está implementada a definição do tabuleiro, as coordenadas de posicionamento das embarcações e as funções de renderização no terminal.
* **`README.md`**: Documentação oficial deste repositório.

---

## 🎮 Mecânica do Desafio

Nesta etapa do desenvolvimento, o sistema foca em consolidar a infraestrutura base da lógica do jogo:
* **Criação do Tabuleiro**: Modelagem de uma matriz bidimensional para representar as coordenadas do oceano.
* **Posicionamento de Navios**: Definição de coordenadas iniciais para posicionar barcos de forma horizontal e vertical no tabuleiro.
* **Exibição em Tela**: Renderização limpa e formatada do estado atual do jogo diretamente no terminal de comandos.

---

## 🧠 Conceitos Praticados e Aprendizados

A construção deste desafio permitiu fixar conceitos intermediários de algoritmos:

* **Matrizes (Arrays Bidimensionais)**: Uso essencial de estruturas do tipo `tabuleiro[linha][coluna]` para criar a malha do jogo.
* **Laços de Repetição Aninhados**: Aplicação prática de estruturas `for` ou `while` dentro de outras para percorrer, preencher e exibir os dados das linhas e colunas da matriz de forma sequencial.
* **Lógica de Coordenadas**: Mapeamento lógico de posições para garantir que os navios ocupem os espaços corretos sem sobreposição e respeitando os limites do tabuleiro.
